# 인공신경망을 이용한 데이터 예측 프로그램

서울시 자전거 대여 데이터를 학습하여 기온, 습도, 풍속에 따른 자전거 대여량을 예측하는 프로그램입니다.

## 사용 데이터
- 데이터 수: 1,000개
- 입력값: 기온(°C), 습도(%), 풍속(m/s)
- 예측값: 자전거 대여량

## 인공신경망 구조
- 입력층: 3개
- 은닉층: 32개, 16개로 구성된 2개 층
- 출력층: 1개

## 주요 기능
- 입력한 기상 조건에 따른 자전거 대여량 예측
- 평가용 데이터의 MAE와 R² 표시
- 실제 대여량과 예측 대여량 비교 그래프

## 사용 도구
Python, Streamlit, pandas, scikit-learn
